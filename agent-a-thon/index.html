🔧 Your Build (Same Shape for Every Agent)

Open Copilot > Agents > Create agent. Get steps 1-3 working in Agent Builder first - depth beats breadth. If you finish early or want to push for the win, level up with steps 4-5 (Copilot Studio + an approval flow).

1Define the Agent Identity
⏱️ ~10 min

Your agent needs an identity before it can do anything. Set its name, persona (who it serves and how it speaks), and the boundary of what it should never say. Goal: A real user looks at the welcome screen and instantly knows what this agent is for.

2Build the Core Topic
⏱️ ~25 min

Pick the ONE question your agent must answer brilliantly. Write the instructions, add the knowledge source (paste relevant content from the company brief or upload a doc), and design a few starter prompts users can click. Goal: One complete, useful answer flow that saves real time.

3Pressure-Test & Refine
⏱️ ~10 min

Now think like a real HHFC colleague and ask hard questions. Does the agent stay on-topic? Does it sound trustworthy? Where does it wobble? Goal: Find one weakness and fix it before you demo.

🚀 Level Up: From Agent Builder to Copilot Studio

Agent Builder is fast and lives inside M365 Copilot - perfect for getting your idea working today. But the moment you want multiple topics, real data connections, or an approval workflow, you graduate to Copilot Studio. The good news: you don't start over. You copy what you built.

4Promote Your Agent to Copilot Studio
🚀 OPTIONAL

Inside Agent Builder, open your agent → click the "⋯" menu on the agent card → choose "Edit in Copilot Studio". Your name, persona, instructions, knowledge sources and starter prompts all carry across. From there you unlock:

  • Multiple Topics - branch the conversation by intent (e.g. "policy lookup" vs "raise a ticket") instead of one big instruction blob
  • Connectors & Knowledge - SharePoint sites, Dataverse tables, public websites, custom APIs
  • Generative orchestration - let the agent reason across all your topics and tools
  • Publish channels - surface the same agent inside Teams, SharePoint, or a custom website

Goal: Open Studio, confirm everything from your Agent Builder version is there, and add ONE thing it could not do before (a second topic, a SharePoint connector, or a published Teams channel).

5Wire In a Real Approval Flow
🚀 STRETCH

A read-only agent answers questions. An agent with an approval flow actually does work on someone's behalf - that is the leap from "neat demo" to "deploy on Monday." From inside Copilot Studio:

  • Open your agent → Topics → create a new topic like "Submit request for approval"
  • Add an Action → "Create a flow" - this opens Power Automate inside Studio
  • Use the "Start and wait for an approval" action - assign it to a manager or shared mailbox, with the request details from the chat as the message body
  • Branch on the outcome: if Approved, post a confirmation back into the agent (and optionally write to SharePoint / Teams / email); if Rejected, ask the user to revise and retry
  • Save and test in the Studio test pane - you should see the approval card land in the approver's Outlook / Teams in real time

Goal: A user can ask the agent for something that requires sign-off (leave request, policy exception, expense top-up, vendor onboarding) and the right Cagamas approver gets a one-click approve/reject card without leaving Teams or Outlook.

💡 Demo tip: If you make it to Step 4 or 5, show it. Triggering a real approval card on stage is one of the most memorable things a team can do in 5 minutes.

💡 Agent Builder Tips

  • Open the right tool: microsoft365.com/copilot → click Agents (top right) → Create agent.
  • Use the Describe tab to chat your agent into existence, then switch to Configure to fine-tune.
  • Knowledge: paste content directly into the Knowledge box, or upload a Word doc. Smaller, focused knowledge usually beats huge dumps.
  • Starter prompts are the agent's "menu" - write 3-4 clickable example questions a user might ask.
  • Test in the right pane as you build - don't wait until the end.

Your Power Up - Who Else Needs This?
Open Microsoft 365 Copilot (not your custom agent - Copilot Chat / m365.cloud.microsoft) and paste this prompt. Replace the bracketed parts with what you actually built today:
"Today I built a Copilot agent at Cagamas called [agent name]. It helps the [team / function] do [what it does]. Based on that, suggest the next three agents Cagamas should build. For each one, tell me: what it would do, which team or job role it would serve, roughly how many people at Cagamas would actively use it each week, and the one piece of knowledge it would need. Then pick the one with the biggest weekly user base and explain why it's the smartest one to roll out next."
💡 One agent is a demo. Three agents = three new teams who'd get value from Copilot every week. That's how this scales at Cagamas.

🎤 Your 5-Minute Demo

  • Slide 1: Which agent you built (or invented) and who it's for
  • Slide 2: The persona & instructions in one screenshot
  • Live demo (most of your time): open the agent and ask 2-3 real questions on screen
  • Slide 3: Where you'd take it next - the upgrade you added (or would add) and who'd be its first real user
  • Show the agent > describe the agent. The judges want to see it work.
